To show **critical impact incidents**, use the `f5-status-get-incidents` tool with the `impact` parameter set to `'critical'`:

## Tool Definition

**Tool:** `f5-status-get-incidents`

**Parameters:**
- `impact` (optional): Filter by impact level — `'none' | 'minor' | 'major' | 'critical'`
- `status` (optional): Filter by status — `'investigating' | 'identified' | 'monitoring' | 'resolved' | 'postmortem'`
- `days` (optional): Lookback period (1-90, default: 7)
- `unresolved_only` (optional): Only return unresolved incidents

## Code Location

- **Tool definition:** [`src/tools/tool-definitions.ts:77-107`](src/tools/tool-definitions.ts#L77-L107)
- **Tool handler:** [`src/tools/tool-handler.ts:138-180`](src/tools/tool-handler.ts#L138-L180) (filters by `impact` on line 147)
- **Type definitions:** [`src/types/api.ts:90`](src/types/api.ts#L90) (incident impact type)

## Usage

```json
{
  "tool": "f5-status-get-incidents",
  "args": {
    "impact": "critical"
  }
}
```

This returns all incidents with `impact === 'critical'`, including:
- Incident ID, name, status, impact
- Created/updated timestamps
- Affected components
- Latest status update
- Summary with count of critical/major incidents
